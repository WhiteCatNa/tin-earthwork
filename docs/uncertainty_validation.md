# 土方量不确定度评定与补测点推荐：方法与仿真验证

本文说明 `core/uncertainty.py` 的方法、仿真验证的设置和结果，以及试过但放弃的方案。数据可用 `docs/validate_uncertainty.py` 复现。

## 1. 问题

TIN 法（以及方格网法、断面法）只给出一个方量数字。工程上真正想知道的还有三件事：这个数有多准，误差主要在哪里，补测哪里最划算。南方 CASS、飞时达、HTCAD、Civil 3D 等常用软件都不回答这三个问题。

TIN 方量的误差分两部分：

- **测量误差**：测点高程的随机误差 σm。方量对高程是线性的，所以 Var = σm²·Σwi²，其中 wi 是测点 i 分担的面积（含该点的三角形面积之和的 1/3）。这部分通常很小。
- **内插误差**：三角形内用平面代替真实地面。它**不是随机的**。凸起处（山包）的平面在真实地面以下，凹处（沟谷）的平面在真实地面以上，所以挖方和填方**都系统性偏小**。测点越稀，偏得越多。仿真中 400 点、200 m × 200 m 的场地，TIN 法挖方的均方根误差约为挖方量的 5~10%，远大于测量误差的贡献。

## 2. 方法

### 2.1 抽稀外推（Richardson 外推）修正内插偏差

对二阶光滑的地面，线性内插在点 p 处的误差为

  e(p) ≈ ½ Σ λi (p − vi)ᵀ H (p − vi)

其中 λi 是重心坐标，vi 是三角形顶点，H 是地面的 Hessian 矩阵。这个误差与边长 h 的平方成正比，所以方量偏差 B(h) ≈ C·h²。

具体做法：

1. 凸包上的测点全部保留，使计算范围不变。内部测点随机保留比例 f（取 0.5），重新构网计算方量 Vk。
2. 抽稀后平均边长变为 h/√f，偏差变为 B/f，所以 Vk − V ≈ B·(1/f − 1)。
3. 重复 K 次（取 8），得到 Dk = (Vk − V)/(1/f − 1)。偏差估计为 B̂ = mean(Dk)，修正后方量为 V − B̂。
4. 内插部分的不确定度为

   σ²interp = sd(Dk)²·(1 + 1/K) + (c·B̂)²，取 c = 1。

   - 第一项是随机抽稀造成的离散。
   - 第二项计入“偏差估计本身不准”：h² 规律只是近似，在测点稀疏、地面起伏尺度接近点距时尤其如此。
5. 总不确定度为 σ² = σ²interp + σm²·Σwi² + (σb·A)²，其中 σb 是可选的系统误差。95% 区间取 ±1.96σ。

挖方、填方、挖填差值分别按上述步骤计算。设计面、挖空区、长边剔除、特征线全部沿用原设置；长边剔除阈值按 1/√f 同步放大。两期对比时，前期和后期的测点同时抽稀；设计三角网保持不抽稀。

### 2.2 补测点推荐

1. **局部弯曲程度**：用留一交叉验证估计。逐个去掉内部测点，用相邻点内插该点，残差 r ≈ κ·ξ·q + 测量误差，其中 q = Σλi|p − vi|²。
   - 加权最小二乘拟合 E[r²] = κ²q² + σm²(1 + Σλ²)，得到全局 κ²。
   - 每个测点处的 κ² 用本点和相邻点的残差估计，并向全局值收缩（相当于 5 个虚拟邻点）。
2. **三角形的误差尺度**：在三角形 T 上积分 q，得 ∫T q = A·Σℓ²/12（ℓ 为三条边长）。所以三角形 T 的方量误差尺度为 κT·gT，gT = A·Σℓ²/12。κT·Σℓ²/12 就是“三角形平均内插误差”，界面上的误差分布图画的就是它。
3. **贪心选点**：在三角形形心补一点，把它分成三个小三角形，g 随之变小，收益为 κT·(gT − Σg子)。每次取收益最大的位置，分出的小三角形继续参与竞选。
4. 落在边界外或挖空区内的位置不推荐。
5. 两期对比时，补测针对后期（现状）地面，因为前期已无法补测。

## 3. 仿真设置

- **场地**：200 m × 200 m，设计高程 50 m。
- **地形**：48 + 0.02x + 12 个高斯山包或洼地。高度服从 N(0, 3²) m，宽度 σ 在 15~50 m 之间均匀分布。每组随机生成一个地形。
- **真值**：用 2000 × 2000 细网格数值积分。
- **测点**：
  - 四角 + n 个内部点。
  - 两种布点：random（均匀随机）和 grid（规则格网，加 0.15 倍格距的扰动，模拟“按格网测量但不严格”）。
  - 高程加 N(0, 0.02²) m 的测量误差。
- **补测对比**：在同一组数据上分别加 10% 的点，一份在推荐位置，一份在随机位置。高程取真实地面加测量误差。比较补测后 TIN 法方量的误差。

## 4. 结果

表中均方根误差的单位为 m³，三个数依次为挖方 / 填方 / 挖填差值。

| 布点 | 组数 | 95% 覆盖率 | TIN 法均方根误差 | 修正后均方根误差 |
|---|---|---|---|---|
| 400 点随机 | 30 | 1.00 / 0.97 / 1.00 | 803 / 776 / 579 | 355 / 301 / 524 |
| 400 点格网 | 30 | 0.93 / 1.00 / 0.93 | 714 / 698 / 669 | 401 / 348 / 568 |
| 1600 点随机 | 20 | 0.95 / 1.00 / 1.00 | 209 / 186 / 131 | 118 / 46 / 140 |
| 900 点格网 | 20 | 0.95 / 1.00 / 0.95 | 375 / 308 / 331 | 200 / 142 / 256 |

| 布点 | 补测点数 | 补测前 | 推荐位置补测后 | 随机位置补测后 |
|---|---|---|---|---|
| 400 点随机 | 40 | 803 / 776 / 579 | 593 / 555 / 239 | 735 / 701 / 531 |
| 400 点格网 | 40 | 714 / 698 / 669 | 434 / 379 / 199 | 637 / 657 / 641 |
| 1600 点随机 | 160 | 209 / 186 / 131 | 147 / 122 / 64 | 198 / 176 / 125 |
| 900 点格网 | 90 | 375 / 308 / 331 | 184 / 164 / 86 | 375 / 268 / 320 |

结论：

1. **偏差修正有效**：修正后挖方的均方根误差下降 44~56%，填方下降 50~75%。挖填差值本身是两个偏差相减，已部分抵消，修正的收益小，个别情况略差。所以界面上挖填差值的区间仍以挖方、填方各自的修正为准。
2. **区间可信**：95% 区间的实际覆盖率为 0.93~1.0。随机布点偏保守（z 的均方根约 0.3~0.6）；规则格网的挖方、挖填差值接近名义值（z 的均方根约 1.0~1.1）。
3. **补测点推荐明显优于随机补点**：同样补 10% 的点，推荐位置使挖方误差下降 26~51%，随机位置只下降 0~11%；挖填差值的误差下降 51~74%，随机位置下降 3~8%。
4. **计算量**：一次评定约做 9 次构网计算。1600 点不到 1 s；1 万点约 4.5 s；5 万点约 21 s，在后台线程运行。

## 5. 试过但放弃的方案

这些结果可以作为论文中的对照或消融实验。

1. **独立误差模型**：把每个三角形的内插误差 κ·ξ·g 当作相互独立的随机量，标定来自留一交叉验证。净方量 z 的均方根约 2.6，区间严重偏窄。原因是相邻三角形的内插误差高度同号。
2. **空间相关模型**：用留一残差的协相关估计 ρ(d) = a + b·exp(−d/L)，再按方格聚合计算方差。
   - 净方量 z 的均方根降到约 1.4。
   - 挖方、填方的 z 均方根仍达 4~6，因为两者被系统性低估：误差的主体是偏差而不是离散，方差模型无法表示。
3. **二阶曲率修正**：用二环邻点拟合二次曲面得到 H，再按 ∫T(内插 − 真值) = A/24·Σ eᵀHe 修正。
   - 400 点时误差下降约 60%。
   - 用真实 H 做对照试验时发现，测点稀疏时二阶近似本身失效，残余偏差仍然同号，区间无法标定。
4. **其他尝试**：
   - 分区（挖方区、填方区）残差均值修正、调节收缩系数：收益很小。
   - 从 1/4 抽稀估计收敛阶 p：估计不稳定。
   - 分层抽稀：比随机抽稀更差。

抽稀外推不需要任何地面光滑性参数，只用测点自身，对布点方式也不敏感。它是上述方案中唯一能同时修正偏差、又给出可信区间的。

## 6. 局限

- 规则格网布点时，抽稀后的点不再规则，偏差估计可能偏小（覆盖率 0.93 左右），程序会提示适当放宽区间。判断依据是最近邻距离的变异系数 < 0.3。
- 若有的地面起伏尺度小于点距（例如漏测的陡坎），任何只用测点的方法都看不出来。这类情况应按特征线（断裂线）处理。
- 补测点推荐基于局部弯曲程度，是启发式的贪心；推荐的位置之间可能比较靠近，现场可适当调整。

## 7. 可能的论文方向

- 题目示例：《基于抽稀外推的 TIN 土方量偏差修正与不确定度评定》，或《顾及内插误差的土方测量补测点优化选取》。
- 贡献点：
  1. 指出 TIN 内插误差以系统偏差为主，而且挖方、填方同时偏小。
  2. 提出用 Richardson 抽稀外推估计并修正偏差，并给出可标定的区间。
  3. 提出基于留一交叉验证局部曲率的补测点贪心选取，用仿真对比随机补点。
- 可补充的实验：
  - 真实工程数据：以密集点云或 LiDAR 为真值，抽稀模拟常规测量。
  - 不同地形粗糙度、点密度、测量误差水平下的敏感性分析。
  - 与 Kriging 方差等地统计方法对比。
