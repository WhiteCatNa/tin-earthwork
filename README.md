# TIN 土方自动算量系统

基于 TIN（不规则三角网）的土方工程量自动计算桌面应用，适用于施工现场测量数据的土方挖填量精确计算。

## 功能简介

- **数据导入**：支持 Excel（.xlsx/.xls）、CSV、TXT、CASS .dat 格式，以及 DXF 地形图和 LAS 点云（见下）；自动识别列映射，也可双击“源列名”手动改选；空值、非数字行会被拒绝并列出行号
- **等高线构网**：从 DXF 地形图读取高程点（POINT、带高程的块）、数字高程注记（TEXT/MTEXT）、等高线（带标高的多段线，样条控制点自动跳过）和 3D 特征线，按图层分组勾选；等高线按给定间距加密取点，构网后统计“三个顶点在同一条等高线上”的平三角形并提示
- **点云导入**：读取未压缩的 LAS 1.0~1.4（点格式 0~10），可只用地面点（分类 2），按格网抽稀（每格取最低点去掉植被、建筑，或取最接近格心的点）；也可**保精度抽稀**（本软件独有）：给定高程容差，平坦处只留很少的点，起伏、坡折处自动加密，保证每个原始点到抽稀后三角网的高差都不超过容差。仿真中 20 万点云只留 0.1%~3% 的点，方量与用全部点构网相差比同点数的格网抽稀小一到两个数量级；LAZ 需先解压
- **测点改错**：在测点表中双击修改、增删测点，支持坐标平移和 X/Y 互换（测量坐标 X 为北向时使用）
- **边界设置**：在平面图上点击绘制计算边界（吸附到测点），或自动生成数据范围边界，或从 DXF / CSV / TXT 导入
- **挖空区**：建筑物、水池等不计方量的区域，可在边界页逐个绘制，或从 DXF（边界内的全部闭合多段线）/ CSV / TXT 导入；挖空区内的方量、面积和零填挖线按多边形精确扣除，凹形挖空区同样精确
- **TIN 构网**：基于 Delaunay 三角剖分；平面坐标重复但高程不同的点会报错，要求先处理，避免随机丢点
- **三角网清理**（可选）：剔除任一边长超过给定值的三角形，去掉测区凹口、凸包边缘的狭长三角形，这些区域不计方量
- **土方计算**：
  - 跨越计算边界的三角形按边界**精确裁剪**，只计边界以内部分（凹边界同样精确）
  - 混合挖填三角形按零填挖线分割，避免正负高差抵消
  - 比较面可选：
    - **统一设计高程**；可加**分区设计高程**（个别点单独指定），文件自带的逐点设计高程同样支持
    - **斜面设计面**：基准点 (X0, Y0)、基准高程 H0、X/Y 双向坡度（%），场平排水坡常用；平面在三角形内线性，结果仍是精确值
    - **设计三角网**：导入设计面数据构成第二个三角网，与实测三角网精确叠加计算；DXF 中读取高程点（POINT、带高程的块）、3DFACE、标高不为 0 的设计等高线和 3D 多段线，也可用表格/文本格式的设计点
    - **两期土方对比**：导入后期测量数据（开挖后、回填后等），前期、后期两个三角网精确叠加后计算两期之间的挖填量；两期测点位置、数量可以完全不同
  - 边界内有区域没有测点覆盖时给出提示（覆盖率低于 99.5%）；两期对比时只计两期都有测点的部分，并提示覆盖比例
- **挖填平衡与土方平衡**：
  - **挖填平衡标高**：统一高程一键求挖填平衡的设计高程；斜面可保持坡度求平衡的基准高程 H0
  - **最小二乘最优斜面**：求与地面最贴合（挖填总量最小）的斜面坡度，再调到挖填平衡
  - **可松性系数**：输入最初可松性系数 Ks、最终可松性系数 Ks'，求平衡时按“挖方自然方 = 填方 ÷ Ks'”平衡；结果给出挖方松方量、填方所需自然方、余土外运松方或缺土外借量
- **等高线**：按给定等高距（或自动选取）生成原地面与设计面等高线，每 5 条一条计曲线；在结果图上显示，导出 DXF 时为带高程的多段线（CONTOUR、CONTOUR_MAJOR、DESIGN_CONTOUR 等图层）并标注高程
- **断面法校核与断面图**（可选）：按推进方向和间距切平行横断面，断面线与三角网逐个三角形求交，断面挖填面积为精确值，相邻断面按平均断面法求方量，与 TIN 法对照；“断面图”页逐个查看断面，PDF 计算书附断面图，Excel 增加断面法一页
- **三维视图**：计算后在结果图左下角打开，原地面按高程着色、设计面（后期面）半透明叠加，可拖动旋转、调整高程夸张倍数、保存图片
- **分层土方**（可选）：按分界高程（如不同土层的分界标高）或按深度（如表土 0~0.3 m）分层统计挖方、填方；被积函数在三角形内分段线性，按半平面精确裁剪积分，各层之和等于总方量
- **土方调配**：计算后在结果图左下角打开；按方格划分调配区，三角形按方格精确切分得到每区挖方、填方及其体积重心，区内先平衡，余缺部分按“方量 × 运距”最小求调配方案（运输问题，线性规划）；给出调配图、调配表、平均运距、余土外运和借土量，可导出 Excel
- **场地放坡**：一个或多个设计平台（从 DXF 闭合多段线导入或直接用计算边界），平台外按挖方、填方坡比自动放坡至与原地面相交；分别给出平台范围和边坡的挖填方，画出坡顶线、坡脚线并可导出 DXF；可让各平台同步升降求放坡后的挖填平衡高程
- **不确定度评定与补测点推荐**（可选，本软件独有）：同类软件只给一个方量数字，这里同时回答“这个数有多准、差在哪里、去哪补测最划算”。
  - 内插偏差修正：TIN 用平面代替真实地面，山包被削平、沟谷被填高，挖方、填方都系统性偏小。程序随机保留一半内部测点重算 8 次（抽稀外推 / Richardson 外推，线性内插误差与边长平方成正比），估计并扣除这部分偏差，给出修正后方量和 95% 区间（内插误差 + 测量中误差）
  - 补测点推荐：留一交叉验证估计各处地面的弯曲程度，画出内插误差分布图，按“误差指标减少最多”贪心选出补测点，在结果图上以 ★ 标出，可导出 CSV / DXF 直接放样；计算时未勾选也可以事后点“不确定度…”在后台补算
  - 仿真验证（5 种布点、两种测量中误差，共 280 组随机地形，其中 160 组为方法定型后才运行的检验组，见 `docs/uncertainty_validation.md`）：修正后挖方、填方的均方根误差下降 40~75%；检验组 95% 区间实际覆盖率 0.95~1.0；按推荐位置补测 10% 的点，挖方误差下降 21~62%，同样数量的随机补点只下降 0~23%
  - 测点接近规则格网时抽稀后的点不再规则，偏差估计可能偏小，程序会提示
  - **按精度目标规划补测**：在不确定度窗口输入目标（如挖方、填方 95% 区间 ±2%），估计还需补测多少点（乐观 ~ 保守两个数），列出第一批补测位置，可导出放样；补测后重新评定，不达标再补下一批
  - **变化显著性**：逐处判断高差是真实挖填还是测量与内插误差。检测限随地面起伏和点距逐处变化，倍数用分裂共形预测标定（内插误差是重尾的，按正态取 1.96 倍会严重偏窄）；两期对比时尤其有用。仿真中未变化区域的误判率 0~1.3%，只计测量误差的常数检测限为 4~34%（四项新功能的方法与仿真见 `docs/innovation_validation.md`）
- **设计面费用优化**（本软件独有）：斜面页点“按费用优化设计面（含调配运距）…”，输入挖、填、运输、余土外运、借土单价和坡度范围，在后台搜索总费用（方量 + 调配运输 + 余缺）最小的斜面，与挖填平衡水平面、最小二乘斜面对照，可一键填回。仿真中比挖填平衡水平面省 25%~54%；默认单价下比最小二乘斜面只省 0~1%，坡度受限或运距单价高时差别才明显
- **方格网法校核**（可选）：按给定边长铺方格网，角点高程由三角网插值，每格分成两个三角形计算（三角棱柱体法），计算范围与 TIN 法一致；给出与 TIN 法的差值和相对差，并输出角点表、方格表和方格网 DXF
- **结果输出**：Excel 报告（汇总、三角形明细、异常数据检查；启用方格网时另含方格网校核、角点、方格三页）、CSV 明细、DXF（计算边界 + 零填挖线；挖空区；等高线；断面线；方格网线、角点施工高度与高程、方格方量，R12 格式）、PDF 计算书、高清图片、文本报告；导出在后台进行，界面不卡顿
- **工程存取**：保存/打开工程文件（测点、边界、挖空区、比较面设置、后期测点、方格网设置、三角网清理、可松性系数、等高线与断面设置、设计点、分层土方、放坡平台、不确定度设置、项目名称），最近工程列表；1.x 的工程文件可直接打开
- **小屏适配**：窗口初始尺寸不超过屏幕；1366×768 笔记本上页头压成一行、列映射可收起、计算设置可滚动，各页主要按钮始终可见

## 环境要求

- **Python 3.13**（推荐）
- macOS / Windows / Linux，需系统提供 Tcl/Tk 支持

> macOS 14 及以上系统请使用 Python 3.13。较早版本 Python 附带的 Tcl/Tk 与新系统存在兼容问题，会导致图形界面启动后异常退出。

## 安装与运行

```bash
# 1. 克隆或解压项目
cd tin_earthwork

# 2. 创建虚拟环境（推荐）
python3.13 -m venv .venv
source .venv/bin/activate   # macOS/Linux
# .venv\Scripts\activate    # Windows

# 3. 安装依赖
pip install -r requirements.txt

# 4. 启动程序
python main.py
```

## 使用流程

1. **导入数据** — 选择文件后点“导入”，核对列映射（可双击改选）和数据质量检查结果，确认进入下一步
2. **设置边界** — 左键逐点添加边界顶点（右键撤销上一点），系统自动闭合；也可自动生成或从 DXF 导入
3. **计算土方** — 选择比较面并填写参数，点击“开始计算”：
   - 统一高程：输入设计高程（可点“从数据估算”），需要时勾选“分区设计高程”单独指定个别点
   - 斜面：填写基准点、基准高程和 X/Y 向坡度（沿 +X/+Y 升高为正）；首次切换时自动填入场地中心和高程中位数
   - 两期对比：数据导入页的测点作为前期，点“导入后期测量数据”选择后期文件（格式同数据导入，自动识别列）；高差 = 前期 − 后期，正为挖除、负为填筑
   - 需要校核时勾选“方格网法校核”并填写边长（默认按场地大小建议 5/10/20 m）

计算完成后可在结果页查看挖填分色平面图、汇总表、三角形明细，点击三角形查看详情，并导出报告。
顶部“项目名称”会出现在所有报告的抬头；保存工程时若未起名，会用文件名作为项目名称。

## 技术栈

| 模块 | 用途 |
|------|------|
| `numpy` / `scipy` | Delaunay 三角剖分、数值计算 |
| `pandas` / `openpyxl` | Excel/CSV 数据读写 |
| `matplotlib` | 平面成果图（TkAgg 后端）、PDF 计算书 |

**2.0.0**

## 开发说明

- **新增导出格式**：扩展 `utils/data_handler.py` 中的 `DataExporter` 类
- **修改计算逻辑**：编辑 `core/calculator.py` 中的 `TINEarthworkCalculator` 类；几何算法在 `core/geometry.py`。各种比较面最终都落到“三角形顶点高差 = 实测 − 比较面”：斜面、分区直接给测点赋设计高程，两期对比由 `core/overlay.py` 叠加出新的三角网，方格网校核通过 `build_from_mesh()` 复用同一套计算
- **调整界面流程**：修改 `gui/` 下各 Frame 类，页面之间通过公开方法（如 `set_points`、`update_inputs`）同步
- **版本号**：只改 `version.py`
