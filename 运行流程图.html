tin_earthwork · 系统说明

TIN 土方自动算量系统
运行流程

从环境准备到三条验证通道，再到应用内的三步作业向导。

一验证与启动

先跑验证再开界面：单元测试确认逻辑，端到端确认全链路，点击压测确认交互不崩、不卡。三条都过了再启动 GUI。

0 · 进入目录并激活环境 cd tin_earthwork source .venv/bin/activate Python 3.13 · 依赖见 requirements.txt
① 单元测试 python -m pytest tests/ -v 覆盖 calculator / data_handler / plotter / boundary / calculation_frame
② 端到端全流程（无需界面） python run_full_test.py --output-dir ./验证输出 导入 → 建网 → 计算 → Excel / CSV / TXT 三份报告落盘
③ GUI 自动点击压测 python tests/gui_stress_test.py 模拟鼠标点击遍历全流程，逐步计时并捕获异常
④ 启动应用 python main.py 1400×900 主窗口 · 三步作业向导

二应用内三步向导

界面按工作流锁定顺序：后一页在前一页确认前是禁用的。计算跑在后台线程，主线程用队列轮询取结果，所以计算过程中界面不会假死。
